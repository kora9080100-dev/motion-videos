# نشر «اكشف الكذبة» على الإنترنت

## الطريقة الموصى بها: Render (فيه خطة مجانية)

الملف `render.yaml` في جذر المستودع يجهّز كل شي. المطلوب منك:

1. افتح <https://dashboard.render.com> وسجّل دخول بحساب **GitHub** حقك.
2. اضغط **New** ← **Blueprint**.
3. اختر المستودع `motion-videos` واسمح لـ Render يوصل له (GitHub بيطلب منك موافقة).
4. في خانة الفرع (Branch) اختر الفرع اللي فيه اللعبة
   (`claude/inspiring-goldberg-6kdv2d`، أو `main` إذا دمجت التغييرات فيه).
5. اضغط **Apply**. البناء ياخذ تقريباً ٣–٥ دقائق.
6. يطلع لك رابط مثل `https://catch-the-liar.onrender.com`، وهذا رابطك اللي ترسله للناس.

> **ملاحظة الخطة المجانية:** إذا ما أحد دخل الموقع ١٥ دقيقة، Render ينيّمه، وأول زيارة بعدها
> تاخذ تقريباً دقيقة لين يصحى. الخطة المدفوعة (Starter) تشيل هذا التأخير.

## (اختياري لكن مفضّل) قاعدة بيانات دائمة عبر Supabase

بدون قاعدة بيانات خارجية، اللعبة تشتغل تمام لكن السجلات والغرف الحية تنمسح إذا أعاد السيرفر التشغيل.
عشان تخليها دائمة:

1. سجّل في <https://supabase.com> وأنشئ مشروع جديد (اختر منطقة قريبة مثل Frankfurt أو Mumbai).
2. من **Project Settings ← Database ← Connection string** انسخ رابط **Session pooler** (URI)،
   وحط كلمة سر قاعدة البيانات مكان `[YOUR-PASSWORD]`.
3. في Render: افتح خدمة `catch-the-liar` ← **Environment** ← **Add Environment Variable**:
   - الاسم: `DATABASE_URL`
   - القيمة: الرابط اللي نسخته
4. احفظ، وRender يعيد التشغيل تلقائياً. الجداول وسياسات الحماية تنشأ لحالها.

> لا تحط هذا الرابط في أي ملف داخل المستودع، مكانه إعدادات Render فقط.

## خيارات ثانية

- **Railway / Koyeb / Fly.io / سيرفر خاص:** استخدم `catch-the-liar/Dockerfile`. المنفذ من `PORT`، وفحص الصحة على `/healthz`.
- **قاعدة بيانات بديلة:** أي PostgreSQL (Neon، Render Postgres، Railway Postgres) عبر `DATABASE_URL`.

## متغيرات البيئة

| المتغير | الوصف |
| --- | --- |
| `DATABASE_URL` | رابط PostgreSQL. إذا فاضي تُستخدم قاعدة مدمجة مؤقتة |
| `DATABASE_SSL` | `disable` / `no-verify` / `verify` (الافتراضي `no-verify` للسيرفرات البعيدة) |
| `PUBLIC_URL` | عنوان الموقع لمعاينة الروابط (يُكتشف تلقائياً) |
| `ALLOWED_ORIGINS` | مصادر إضافية مسموح لها بالاتصال المباشر |
| `ADS_ENABLED` | يبقى `false` لين يتربط مزود إعلانات حقيقي |

## التوسّع لاحقاً

الخادم يحتفظ بالغرف الحية في ذاكرته، فالأفضل تشغيل **نسخة واحدة** (تكفي آلاف اللاعبين بنفس الوقت).
إذا احتجت أكثر من نسخة: أضف Redis adapter لـ Socket.IO مع توجيه ثابت (sticky sessions) حسب رمز الغرفة.
