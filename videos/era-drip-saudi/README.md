# Era Drip — زيارة رسمية

فيديو طولي 1080×1920، ‏30fps، ‏18.5 ثانية. نفس فايب المقطع السعودي المرجعي (الصقر، العلم، السجاد البنفسجي، حرس الشرف، عرض الطيارات)، بس البطل هنا كوب Era Drip: يوصل كضيف رسمي ويستقبلونه بالمراسم.

النسخ النهائية:
- `out/era-drip-saudi.mp4`: موسيقى ومؤثرات مولّدة على نفس الإيقاع
- `out/era-drip-saudi-music.mp4`: نفس الفيديو بموسيقى المقطع المرجعي

## التشغيل
```bash
npm ci
python3 scripts/make_sfx.py           # يولّد المؤثرات والموسيقى في public/sfx
npx remotion studio
npx remotion render EraDripSaudi ../../out/era-drip-saudi.mp4
npx remotion render EraDripSaudiMusic ../../out/era-drip-saudi-music.mp4
```

## المصادر
- ملف العلم: `country-flag-icons` (رخصة MIT)، باللون الأخضر الرسمي #006c35. ما يُقلب ولا يُعكس في أي مشهد.
- رسمة الباريستا: مأخوذة من شعار Era Drip ومحوّلة لرسم متجه.
- المقاطع: مقاطع المحل اللي أرسلها صاحب الطلب.
