# مرجع الموشن جرافيك — 11 مقطع مرجعي

> هذا الملف هو المرجع الأساسي لأي طلب موشن جرافيك. قبل تنفيذ أي فيديو أو كتابة برومبت أو سكربت، ارجع لهذا الملف، اختر المرجع الأقرب للطلب، وطبّق القواعد المشتركة في الأسفل.

---

## القواعد المشتركة (DNA مشترك بين كل المراجع)

1. **الطول:** 14–44 ثانية. الأغلب بين 20 و 35 ثانية.
2. **الإيقاع:** مشهد جديد كل 1–2.5 ثانية. لا يوجد مشهد ثابت أكثر من 3 ثوانٍ.
3. **الهيكل:** Hook (سؤال/مشكلة) ← تصعيد المشكلة ← الحل/المنتج ← المزايا ← الشعار/CTA.
4. **النص هو البطل (Kinetic Typography):** كلمة أو كلمتين على الشاشة في وقت واحد، تظهر حرفاً بحرف أو كلمة بكلمة مع Blur-in، Scale، أو Mask reveal. الكلمة المفتاحية بلون مختلف أو وزن أثقل أو حجم أكبر.
5. **الانتقالات:** Match cut، Zoom-through (الكاميرا تدخل داخل عنصر)، Whip/Motion blur، عنصر يتحول لعنصر آخر (Morph). شبه ما فيه Cut عادي جاف.
6. **الحركة:** Easing ناعم (Ease in-out قوي / Overshoot بسيط)، Motion blur على الحركات السريعة، كاميرا 2.5D/3D تتحرك باستمرار (Dolly, Tilt, Orbit).
7. **الخلفيات:** نظيفة جداً — أبيض/رمادي فاتح، أو أسود، أو تدرج ناعم. العنصر الرئيسي في المنتصف دائماً.
8. **عناصر الواجهة (UI):** كروت بزوايا دائرية + ظل ناعم، شريط بحث، أزرار، Toggle، Progress bar، Cursor/يد تضغط. أسلوب Apple/iOS منتشر بقوة.
9. **لوحة ألوان محدودة:** لون أساسي واحد + أبيض/أسود + لون Accent واحد.
10. **الختام:** شعار البراند أو اسم صاحب الحساب مع Blur/Fade، ثم الإطار الأخير.
11. **الصوت:** موسيقى إيقاعية + SFX (Whoosh, Click, Pop, Swoosh) متزامنة مع كل حركة.

## المراجع بالتفصيل

### 1) iFood — إعلان تطبيق توصيل (UI Motion)
- **المقاس/المدة:** 640×576 (قريب من مربع) · 18 ثانية
- **الأسلوب:** UI animation نظيف على خلفية بيضاء، لون أساسي أحمر (#EA1D2C تقريباً).
- **التسلسل:** أيقونة التطبيق ← شريط بحث يتمدد ويكتب "Buscar Comidas Locais" مع مؤشر كتابة ← يد/Cursor تضغط ← كروت أطباق (سوشي، بطاطس، بيتزا) تدخل بـ Carousel 3D مع ضبابية ← عنوان "Tudo pra facilitar seu dia a dia" يظهر حرف بحرف بمسار منحني ← بانرات عروض بالأسفل ← ضغط "Pedir Agora" ← Progress bar مع موتر توصيل يتحرك "Pedido a caminho" ← كرت أحمر ✓ "Pedido Entregue" ← اسم الحساب.
- **أهم تقنيات:** Typewriter text، Cursor-driven storytelling، Card carousel بعمق، Progress bar كأداة سرد، Squash & stretch بسيط على الكروت.
- **يصلح لـ:** إعلانات تطبيقات، توصيل، متاجر إلكترونية، شرح رحلة المستخدم (User Flow).

### 2) iPhone — أسلوب إعلانات Apple
- **المقاس/المدة:** 1024×576 (16:9) · 36 ثانية
- **الأسلوب:** Minimal Apple style — نص أسود صغير وسط شاشة بيضاء، ثم لقطات منتج 3D.
- **التسلسل:** "iPhone" ← "Our fastest model yet." ← Zoom قريب جداً على الكاميرا الخلفية مع Motion blur ← "All day battery life." منحني فوق صورة الشاشة ← أجهزة تطير وتدور في الفراغ ← "Colors" بأجهزة بألوان مختلفة ← جهاز يدور ← أجهزة نائمة متقاطعة ← "iOS" ← صف شاشات (Lock screen) ← "Dynamic Wallpapers" ← واجهة الكاميرا ← App Store ← iMessage ← "Smooth. Stylish." ← "That's…" ← نهاية سوداء.
- **أهم تقنيات:** Big-to-small product reveal، Floating 3D devices، Text-only beats بين لقطات المنتج، Screen recordings داخل إطار الجهاز.
- **يصلح لـ:** إطلاق منتجات تقنية، أجهزة، تطبيقات بمظهر فاخر.

### 3) Opptics × Whop — إعلان Fintech بأسلوب 3D مبهر
- **المقاس/المدة:** 1024×576 (16:9) · 25 ثانية
- **الأسلوب:** 3D لامع (Glossy) وألوان مشبعة، كروت بنكية وأيقونات Claymorphism.
- **التسلسل:** كروت مشاكل تتكدس (Payment holds 🚫 / Account Bans 🚫 / No Control / No Data) مع عناصر 3D (حصالة، ترس، بطاقة VISA مقفلة) ← انفجار ألوان أسود ← شعار Opptics × Whop مع أشعة ملونة (Light rays) ← "The future is here!" بتدرج بنفسجي ← "Get Paid in 1-2 Days" بإضاءة ذهبية وحصالة ذهبية ← "Lowest Fees: Industry Avg 4-6% ← As Low As 2%" داخل دائرة متوهجة ← "Superior approval rates" مع Memoji ونافذة "congratulations!" ← "Switch today at" مع Toggle أخضر ← شعار نهائي على أزرق.
- **أهم تقنيات:** Problem stack ثم Explosion reveal، Glow/Bloom، أرقام مقارنة (قبل/بعد)، تغيير لون المشهد بالكامل حسب المزاج (داكن للمشكلة، ذهبي للمكسب، أزرق للثقة).
- **يصلح لـ:** Fintech، SaaS، إعلانات بمقارنة مع المنافس.

### 4) روف (Roof) — موشن عربي لخدمات إلكترونية (مولّد بالذكاء الاصطناعي من برومبت)
- **المقاس/المدة:** مصوّر من الشاشة 576×1024 · 34 ثانية — الفيديو عمودي (9:16) معروض بجانب البرومبت.
- **الأسلوب:** أحمر وأبيض فقط، عناصر ورقية/كروت 3D ناعمة، خط عربي عريض.
- **التسلسل:** "شغل؟" ← "مشروع؟" ← شعار "روف · للخدمات الإلكترونية" ← "تصميم" ← موكاب جوال مع أيقونات تدور حوله ← "إدارة حسابات" بكروت ← "محتوى" بأوراق ← "واجبات" بورقة وقلم ← "احتراف" بتوهج أحمر على أسود ← أيقونات خدمات بشبكة (Grid) ← "روف — فكرتك علينا".
- **أهم تقنيات:** كلمة واحدة لكل خدمة، كل خدمة لها عنصر بصري، Grid reveal للخدمات في النهاية، Brand color واحد.
- **ملاحظة:** هذا المرجع يوضح أن البرومبت المفصّل (مشهد بمشهد) هو اللي ينتج هذا المستوى.
- **يصلح لـ:** إعلانات خدمات عربية، وكالات، متاجر خدمات طلابية.

### 5) Notes ← Calendar — قصة بعناصر iOS (henryexists)
- **المقاس/المدة:** 576×576 (مربع) · 14 ثانية
- **الأسلوب:** Native iOS widgets على رمادي فاتح.
- **التسلسل:** ويدجت Notes "What is my biggest problem?" يكبر ← Checklist: Quality ✗ / Quantity ✗ / Consistency ✓ مع Motion blur ← "let's fix that" بلون قوس قزح ← "today." أزرق على أسود ← أيقونة Calendar "11" ← دائرة حمراء 11 تكبر ← تقويم أغسطس يتلوّن أسبوع بعد أسبوع حتى 26 ← اسم الحساب.
- **أهم تقنيات:** Zoom-through بين الويدجتات، Checklist كأداة سرد، Highlight تدريجي في التقويم يمثّل "الاستمرارية"، قصير جداً ومكثّف.
- **يصلح لـ:** محتوى تحفيزي/إنتاجية، ريلز قصيرة، Personal brand.

### 6) HowDo (Sleeko) — Product launch بهيكل مقسّم
- **المقاس/المدة:** 768×576 · 44 ثانية
- **الأسلوب:** تدرجات بنفسجي/وردي، عناصر 3D ناعمة، صور حقيقية مدمجة. يظهر أسفل الفيديو شريط أقسام: Intro / Problem / Use Case / Call to Action (مرجع لتقسيم السكربت).
- **التسلسل:** Intro: جوال 3D مع عناصر تطفو حوله "HowDo" ← Problem: "Every day, there's something…" مع أيقونات صغيرة ← "You just want solution?" ← كولاج صور يدور "but find the solution" ← Use Case: دائرة تتحول لشاشة كمبيوتر ← Zoom داخل الشاشة ← سؤال "want pizza?" ← جوال بيد يصور بيتزا ← "Whatever you are doing" ← "New ⏰ product" ← QR على علبة ← واجهة التطبيق ← CTA: "Learn it" ← غيوم ← شعار HowDo.
- **أهم تقنيات:** Section-based storytelling، Zoom into screen، Icons تتطاير حول النص، Mixed media (3D + فوتو حقيقي).
- **يصلح لـ:** إطلاق تطبيق/منتج AI، فيديو شرح (Explainer).

### 7) ROAR — رحلة البراند (عربي، سعودي)
- **المقاس/المدة:** 576×1024 (9:16) · 39 ثانية
- **الأسلوب:** خلفية بيج/كريمي، لون Accent عنابي/أحمر، شخصيات بالزي السعودي (صور AI/مركبة)، خط عربي عريض.
- **التسلسل:** "براند جديد" بشخص في خط بداية سباق ← "لا تشتت أهم مرحلة فيه" بشخص سادد أذنه ← لقطة علوية لطاولة "جهة تختار الاسم" / "جهة تصمم الهوية" ← "وبالنهاية" ← "يطلع كأنه 5 مشاريع" ← "في ROAR نسهّل الرحلة" ← خريطة بدبابيس ومسار يُرسم (الاسم ← الهوية ← المواقع ← حملة الإطلاق) ← "نختار إسم" بنبتة في أصيص ← "ونسق إجراءات تسجيل العلامة" بأوراق ← "بعدها نبني الهوية والتغليف" بموكاب منتجات ← موقع "Desserts Crafted to Delight" ← جدار تغليفات ← تصاميم سوشال ← "عندك فكرة جاهزة للسوق؟ عبي النموذج الآن".
- **أهم تقنيات:** Metaphor لكل خطوة (سباق، نبتة، خريطة)، Map path animation، Portfolio wall في النهاية، CTA نصي بسيط.
- **يصلح لـ:** وكالات براندنق، خدمات B2B عربية، عرض مراحل خدمة.

### 8) بودكاست + Motion captions (sbaix_7) — Before/After
- **المقاس/المدة:** 384×720 (9:16) · 25 ثانية

### 9) Stop Waiting — تحفيزي بأسلوب مسطح أزرق
- **المقاس/المدة:** 576×1024 (9:16) · 21 ثانية
- **الأسلوب:** أبيض + أزرق واحد (#1E88F0 تقريباً) + أصفر/برتقالي، دوائر بلور، صور Cutout.

- **يصلح لـ:** اقتباسات، محتوى تحفيزي، Quotes animation.

### 10) Collage / Retro Cut-out (cassiusgeo)

## طريقة الاستخدام عند أي طلب موشن جرافيك
1. حدد نوع الطلب واختر 1–2 مرجع من الجدول.
2. اكتب السكربت بهيكل: Hook ← Problem ← Solution ← Benefits ← CTA (مثل مرجع 6).
3. اكتب برومبت مشهد بمشهد (مثل مرجع 4): لكل مشهد = النص على الشاشة + العنصر البصري + نوع الحركة + الانتقال + المدة.
4. ثبّت: لون أساسي واحد + Accent، خط واحد أو خطين، خلفية نظيفة، 1–2.5 ثانية لكل مشهد، SFX على كل حركة.
5. اختم بالشعار/CTA.
